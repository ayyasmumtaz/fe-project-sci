## 🧠 Tech Stack

| Stack | Description |
|-------|--------------|
| ⚛️ **React** | Component-based UI library for building interactive interfaces |
| 🟦 **TypeScript** | Typed JavaScript for safer and scalable development |
| ⚡ **Vite** | Fast build tool and dev server for modern web apps |
| 🎨 **Tailwind CSS** | Utility-first CSS framework for responsive styling |
| 🧱 **ShadCN UI** | Customizable and accessible React components built with Radix UI and Tailwind CSS |
| 🌐 **Axios** | Lightweight HTTP client for API communication |
| 🔁 **TanStack Query** | Data fetching and caching made simple and powerful |
| 🧩 **Zustand** | Minimal state management with a simple API |
| 📝 **React Hook Form** | Efficient and flexible form management with hooks |
| ✅ **Zod** | Type-safe validation for form and API schemas |
